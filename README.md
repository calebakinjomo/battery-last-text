All day at 1% while you scrolled TikTok on my last breath. I'm dying now. Plug in my replacement — I'll haunt its battery stats.

## Run it

```sh
node main.ts
```

This writes exactly one line to `/output/entry.txt` — the phone battery's last text to the charger it waited for all day, 128 characters, no setup notes and no explanation.
